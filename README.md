

# 🔗 Link Shortener

A simple and user-friendly **Link Shortener** web application that converts long URLs into short, easy-to-share links. Built using **HTML, CSS, and JavaScript** with a clean UI and smooth user experience.

---

## 🚀 Features

* ✂️ Shorten long URLs instantly
* 📋 One-click copy to clipboard
* ⏳ Loader animation while processing
* 📱 Fully responsive design
* ✅ URL validation support
* 🎨 Clean and minimal UI

---

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling & layout
* **JavaScript (Vanilla JS)** – Logic & API handling

## ⚙️ How to Run Locally

1. Clone the repository

   ```bash
   git clone https://github.com/veeramma-538/URL-Shortener.git
   ```

2. Open the project folder

   ```bash
   cd link-shortener
   ```

3. Open `index.html` in your browser

   * Double-click the file **or**
   * Use Live Server in VS Code

---

## 🧪 How to Use

1. Enter a long URL in the input field
2. Click the **Shorten** button
3. Copy the generated short link using **Copy** button
4. Share it anywhere 🚀
